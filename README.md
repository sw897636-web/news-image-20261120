A newspaper front page that sums up Friday 20 November 2026 in four stories: Cyclone Akvan slamming into India's east coast; Trump, Xi and Putin sitting down together in Shenzhen; the top UN court ruling Myanmar guilty of genocide; and Anthropic's $2 trillion market debut. One day, four headlines, one front page.

## How it works

`main.ts` (Node 22, standard library only) copies the `entry.png` image stored in this repository to the output directory, byte for byte — `MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`. Run it with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
